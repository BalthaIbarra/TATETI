# Ta Te Ti

Juego de Ta Te Ti hecho con HTML, CSS y JavaScript.

## Cómo jugar

- Son 2 jugadores (X y O) y cada uno tiene 3 fichas.
- Se turnan para colocar las fichas en casillas vacías.
- Cuando las 6 fichas están en el tablero, en cada turno se mueve una ficha propia a una casilla vecina libre.
- Gana el primero que logra 3 fichas en línea (horizontal, vertical o diagonal).

## Cómo ejecutarlo

Abrir `index.html` en el navegador.
